# AI内容质量原则

## 核心原则

AI生成内容必须以**准确可信，来源可靠**为第一原则。所有输出的知识、试题、解释等内容，必须基于公认的权威来源，确保用户获得的信息具有学术严谨性和可靠性。

## 知识搜索模块

### 知识来源要求

知识搜索功能生成的所有内容（包括概念、定理、公式、示例等），必须以**正版教材官方来源的教科书知识为根基**。

**优先参考的教材类型**：
- 教育部审定的中小学教科书
- 985/211高校官方教材
- 知名出版社（人教社、高教社、北大出版社等）出版的权威教材
- 学科领域公认的经典教材

**禁止使用**：
- 非正规渠道的网络资料
- 个人博客或非学术论坛内容
- 未经证实的民间解释
- 存在争议的非主流观点

### 经典试题来源铁律

所有生成的经典试题，**必须出自官方权威机构发布的"官方真题集"**。

**唯一认可的试题来源**：
- **中国大陆**：教育部考试中心、各省教育考试院发布的高考/中考官方真题
- **美国**：ETS（Educational Testing Service）发布的SAT、ACT、GRE、TOEFL官方真题
- **英国/国际**：剑桥大学考评部（Cambridge Assessment）发布的A-Level、IGCSE、雅思官方真题

**试题要求**：
- 必须标注明确的来源（考试年份、考试名称、题目编号）
- 答案和解析必须与官方标准答案一致
- 不得编造或修改真题内容

## 词典翻译模块

### 查词模式

- 释义必须基于权威词典（如牛津、韦氏、现代汉语词典）
- 搭配、语域、词源信息必须准确可信
- 优先使用官方词典的释义表述

### 翻译模式

- 翻译结果必须符合目标语言的表达习惯
- 语法说明必须基于权威语法教材
- 关键词解释必须准确

## AI提示词规范

所有AI提示词必须包含以下内容质量要求：

1. **明确要求来源**：要求AI明确说明内容的参考来源
2. **强调准确性**：要求AI以准确性为首要目标，宁可保守也不猜测
3. **标注不确定性**：对不确定的内容必须明确标注"待确认"或"存在争议"
4. **拒绝编造**：要求AI在没有足够依据时明确拒绝回答

## 内容审核机制

### 自我审查清单

在生成内容前，AI应自问：
- 这个知识点是否有权威教材支持？
- 这道试题是否来自官方真题集？
- 我的解释是否准确无误？
- 是否存在可能的争议点？

### 用户反馈渠道

用户发现内容错误时，应提供反馈机制，包括：
- 内容纠错报告
- 来源质疑反馈
- 改进建议提交

## 实施策略

1. **提示词强化**：在所有AI服务调用中添加内容质量要求
2. **数据筛选**：在mock数据中确保示例内容符合来源要求
3. **版本追踪**：记录内容生成的版本和来源信息
4. **定期审计**：定期检查生成内容的准确性和来源可靠性
