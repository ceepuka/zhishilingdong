# 知识灵动助手 - 项目总目标

## 目标描述

AI驱动的知识办公Web应用，以"知识可视化"为核心交互语言，整合知识搜索、词典翻译、文档生成三大核心功能。

一句话定位：**搜知识、查翻译、写文档 —— 用可视化让知识一目了然。**

## 核心价值

- 知识可视化：将复杂知识转化为直观的图表、流程、对比等形式
- 一站式知识办公：搜索、翻译、文档生成一体化
- AI驱动：智能理解用户需求，提供精准响应

## 目标状态

**产品阶段：开发期（未正式落地）** 🚧 - 产品尚未正式发布、无线上用户、无存量数据。本阶段不考虑向后兼容、不写数据迁移、不保留 deprecated 兼容层，被替代的代码直接删除（详见 [project-document-manager.md](project-document-manager.md) 顶部「产品生命周期阶段」）。

**v1.6.0 已完成** ✅ - 真实AI服务集成、多语言 i18n、真流式生成、生成超限自动续写、查词/翻译改造、知识搜索内容增强均已完成；知识图谱导航暂不考虑，6种知识卡片组件为死代码待处理，响应式适配待做（详见下方功能清单）

## MVP核心能力

1. **知识搜索** —— 搜索框 + 热门标签 + 搜索范围标签 + 思维导图 + 概念/示例/试题/脉络/趣味 + 知识目录占位
2. **词典翻译** —— 查词 + 翻译模式（手动切换）+ TTS朗读
3. **文档生成** —— 11种文档类型 + Markdown渲染 + 多格式导出 + 复制

### 知识搜索模块

- [x] 核心概念卡片（定义/公式/定理/原理 4种子类型，初等+高等两层解释，关键要点 + 易错提醒，KaTeX公式渲染）
- [x] 核心概念总述（conceptsOverview，标题下、概念卡片之前）
- [x] 示例演示卡片（独立卡片，步骤编号 + 结论 + 公式）
- [x] 知识脉络（学习路径→前置知识/关联主题→易混辨析→常用结论 四段式）
- [x] 经典试题（选择/填空/计算/问答 + 难度 + 答案解析 + 来源标注 + 折叠查看；题型中英别名归一化、选项归一化、答案收敛字母）
- [x] 趣味知识（故事/应用/历史/趣味）
- [x] 配图四通道（`image` 可信直链 → `imageData` 多模态 base64 → 关键词检索 → 模型内联 SVG；加载失败逐级回退）
- [x] 知识内容导出（TXT / Markdown / HTML / Word(.docx) / PDF）+ 复制功能（复制与导出**同一份序列化源**，口径一致）
- [x] 追问对话功能（与AI服务集成）
- [x] 搜索状态机（IDLE→VALIDATING→ANALYZING→KNOWLEDGE_GRAPH/GENERATING→DISPLAYING→FOLLOWUP）
- [x] 流式生成（单次调用 `generateStream`，AI 边写 / UI 边读共享缓冲区实时渲染；不支持流式时自动降级）
- [x] 生成超限自动续写（严格闭合判定 + 最多 3 次尝试，未写完回填尾部要求只输出续写，`continued` 提示）

- [x] 知识目录占位组件（div 层级树，非 SVG 知识图谱）

### 词典翻译模块

- [x] 查词结果：音标、词性、释义、例句、同反义词、关联术语、常用搭配、语域、词源；支持短语/多词（≤10 个关键词）

- [x] 输入上限与计数（查词 120 / 翻译 3000，超长截断提示）
- [x] TTS朗读功能（单词发音、句子原文/译文朗读，朗读状态反馈）
