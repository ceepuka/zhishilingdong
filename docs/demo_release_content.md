#

### 1. Demo 简介

**产品形态**：基于 React + TypeScript + Vite 构建的单页 Web 应用，可直接通过浏览器打开运行，无需安装任何依赖。

**面向人群**：学生、教师、职场学习者等所有需要学习和查询知识的人群。

**核心功能**：

- **智能知识搜索**：输入知识点关键词，AI 实时流式生成思维导图、核心概念（初等/高等双层解释 + 关键要点 + 易错提醒 + 配图）、典型示例、知识脉络、经典试题和趣味知识，支持搜索和问答两种交互方式；内容被模型上限截断时自动续写补全。
- **思维导图可视化**：动态绘制思维导图，支持 3-4 层深度、3-5 个一级分支，节点标题悬停显示完整内容，使用直角折线连接，布局自动计算。
- **多功能翻译助手**：支持单词/短语查询（音标、词性、释义、搭配、语域、词源）和文本翻译（源/目标语言双下拉），译文逐段对齐、选词实时映射，提供多种翻译风格选择。
- **文档生成工具**：支持生成通用文档、邮件、报告、会议纪要、PPT 大纲、笔记、合同、简历、新闻稿、提案、周报等多种文档类型。
- **多语言界面**：中英文界面切换，AI 输出跟随用户语言。
- **收藏与历史管理**：支持收藏重要内容，管理浏览历史，自动更新时间显示。

### 2. Demo 创作思路

**灵感来源**：在日常学习和工作中，我们经常需要查阅各种知识资料，但分散在不同的教材、网站和文档中，获取信息效率低下。希望打造一个一站式的智能知识助手，让用户能够快速获取系统化的知识内容。

**想解决的问题**：

- 知识获取碎片化：用户需要在多个平台之间切换，无法快速获取完整的知识体系。
- 学习效率低：缺乏系统化的学习路径和关联知识推荐。
- AI 内容质量不稳定：现有 AI 工具生成的内容格式不一，缺乏规范性和权威性。

**为什么做这个方向**：

- AI 大模型的普及为智能知识生成提供了技术基础。
- 教育领域对智能化学习工具的需求日益增长。
- 通过严格的提示词工程和数据清洗，可以确保 AI 生成内容的质量和规范性。
- 模块化架构设计使产品具有良好的可扩展性。

### 4. TRAE 实践过程

**开发流程**：

1. **项目初始化**：使用 Vite + React + TypeScript 搭建项目框架，配置 Tailwind CSS。
2. **模块设计**：设计搜索、翻译、文档、收藏四大核心模块，采用状态机管理搜索流程。
3. **思维导图实现**：实现动态布局算法，支持任意深度和分支数量，处理极端场景（如 10 个一级分支）。
4. **AI 集成**：接入 OpenAI 兼容协议的多厂商模型，设计分模式的提示词策略（搜索/问答/查词/翻译/文档），实现**真流式生成**（单次 `generateStream` 调用，增量 JSON 解析让 AI 写入与 UI 渲染共享缓冲区实时呈现）+ **超限自动续写**（最多 3 次）。
5. **JSON 解析容错**：建立多层修复体系，处理 AI 返回的不规范 JSON（中文标点、非法转义、截断等）。
6. **用户体验优化**：添加历史记录管理、收藏功能、清空确认对话框、节点标题悬停显示等交互细节。

### Tips：开发中的踩坑经历

1. **思维导图布局算法**：最初使用固定层级和分支数量，导致 AI 生成数据偏离规范时布局混乱。后来重构为动态布局算法，支持任意深度和分支数量。
2. **JSON 解析失败**：AI 返回的 JSON 经常包含中文逗号、LaTeX 非法转义、截断等问题。通过建立多层修复体系（字符清洗、非法转义修复、尾随逗号移除、迭代式截断修复）解决。
3. **AI 生成内容质量**：最初将所有模式的提示词放在一起，导致相互干扰。后来拆分为独立的提示词策略，每种模式（搜索/问答/查词/翻译/文档）使用独立的 system prompt。
4. **token 限制截断**：AI 生成内容超过 token 限制时被截断，导致 JSON 解析失败（旧实现还会把截断伪装成完整结果）。通过①按深度设置输出预算并夹在模型输出上限内（`min(基线, 模型上限, 上下文×40%)`）②从 `finish_reason` 逐层透出截断标记并明确提示③**自动续写补全（最多 3 次）**解决；同时保留 JSON 迭代式截断修复。
5. **React key 冲突**：AI 在不同分支下生成相同的节点 ID（如 l1, l2），导致 React key 警告。通过路径前缀法生成全局唯一 ID（如 r-b1-l1）解决。
