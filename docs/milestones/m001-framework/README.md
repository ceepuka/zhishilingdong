## 目标描述
创建项目整体框架和导航系统，包含顶部导航栏、Tab切换、响应式布局、主题切换。

## 完成内容
- [x] 顶部导航栏（Logo + Tab 切换按钮 + 全局菜单）
- [x] **4 个 Tab**：知识搜索、词典翻译、文档生成、收藏
- [x] URL hash 变化（#search / #translate / #doc / #favorites）
- [x] 响应式布局（最大宽度 1200px 居中）
- [x] 主题配色（默认亮色：teal 主色、amber 辅色；深色模式：zinc 中性灰色系）
- [x] 主题切换（useSyncExternalStore，防闪烁内联脚本）
- [x] 语言切换（中文/English）
- [x] 全局菜单（主题/语言/清空所有历史，带确认对话框）

## 技术实现
- **构建工具**：Vite 5.x + TypeScript 5.x
- **UI 框架**：React 18.x
- **样式方案**：Tailwind CSS 3.x
- Tab 切换通过 URL hash 同步 + 状态管理
- 主题通过 `useSyncExternalStore` 订阅，避免多实例不同步
- 防闪烁：HTML 内联脚本在 React 加载前读取主题
