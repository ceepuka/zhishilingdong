## 目标描述
创建词典翻译模块，支持查词和翻译两种模式。

## 完成内容
- [x] 文本输入框（支持单词和段落）
- [x] 语言方向切换按钮（中→英 / 英→中 / 自动检测）
- [x] **手动切换**查词模式 / 翻译模式（不自动检测输入内容，避免反直觉）
- [x] 查词模式：音标、词性、释义、例句、同义词/反义词、关联术语、常用搭配、语域、词源
- [x] 翻译模式：原文/译文对照、风格切换（学术/商务/日常）、关键词、语法说明
- [x] TTS 朗读功能（单词发音、句子原文/译文朗读，朗读状态反馈）
- [x] 生词收藏功能
- [x] 与真实 AI 服务集成（智谱 GLM-4-Flash）

## 技术实现
- **模式切换**：用户手动切换查词/翻译模式，不基于输入内容自动判断
- 查词模式展示多义项和例句
- 翻译风格切换：`performTranslateWithStyle` 点击风格按钮重新调用 AI 翻译
- 翻译模式隐藏语言方向按钮
