## 目标描述
完善追问对话功能，支持基于当前知识点的连续追问和对话历史记录。

## 完成内容

- [x] 追问等待提示（QASection 添加 isLoading）
- [x] 防重机制（processingRef）

## 技术实现
- 对话数据结构：`ChatMessage` + `QASession`（types/index.ts）
- 本地存储：HistoryContext + Context 模式（替代 useState+key prop）
- 接口复用：`followup(query, history, mode)` —— `mode: 'search' | 'qa'`
  - search 模式：基于 topic + 历史回答追问
  - qa 模式：基于历史对话直接回答
- 系统提示词：按模式区分，搜索/问答 prompt 完全分离
- 历史标识：以第一条消息为标识，避免追问覆盖浏览中标记
