## 目标描述
创建文档生成模块，支持多种文档类型的生成。

## 完成内容
- [x] **11 种文档类型**：通用、商务邮件、报告大纲、会议纪要、PPT结构、学习笔记、合同、简历、新闻稿、项目方案、周报
- [x] 文档类型选择器（折叠/展开效果，移到输入框下方）
- [x] 需求描述输入框（支持多行）
- [x] 生成按钮
- [x] 生成完整文档内容，Markdown 渲染（react-markdown + remark-gfm）
- [x] 商务邮件语气风格切换（正式/友好/简洁）
- [x] 一键复制全文
- [x] 文档导出（TXT/Markdown/PDF，PDF 支持中文和分页）
- [x] 文档收藏功能
- [x] 浏览中状态修复（currentTopic 替代 result.title）
- [x] 与真实 AI 服务集成（智谱 GLM-4-Flash）

## 技术实现
- 文档类型通过 DocTypeSelector 组件选择（可折叠）
- 生成结果用 react-markdown 渲染富文本
- PDF 导出使用 jspdf，支持中文和分页
- 复制使用 Clipboard API
