## 目标描述
创建知识搜索模块，包含搜索输入区、知识卡片展示区、追问对话区。

## 完成内容
- [x] 大搜索框居中，实时联想补全
- [x] 热门标签（物理定律、化学反应、数学公式等）
- [x] 搜索范围标签（按 category/tags 过滤，支持清空、折叠）
- [x] 思维导图（两阶段递归布局算法、画布拖动、直角折线连接、叶子描述外置）
- [x] 核心概念卡片（定义/公式/定理/原理 4 种子类型，初等+高等两层解释，KaTeX 渲染）
- [x] 示例演示卡片（步骤编号 + 结论 + 公式）
- [x] 知识脉络（前置知识、关联主题、学习路径、常用结论）
- [x] 经典试题（选择/填空/计算/问答 + 难度 + 答案解析 + 来源标注 + 折叠查看）
- [x] 趣味知识（故事/应用/历史/趣味）
- [x] 追问对话区（基于当前知识点的连续追问，与 AI 服务集成）
- [x] 操作栏（复制、收藏、导出 Markdown）
- [x] 搜索状态机（IDLE→VALIDATING→ANALYZING→KNOWLEDGE_GRAPH/GENERATING→DISPLAYING→FOLLOWUP）
- [x] 流式生成（单次调用 `generateStream`：AI 边写 / UI 边读共享缓冲区实时渲染；早期为 3 步 `generatePartial`，已废弃）
  - 历史说明：`generatePartial` 分多次 fetch 的方案因频繁中途失败已移除，接口与提示词均已从代码库删除，仅历史文档仍有记载
- [x] 知识目录占位组件（div 层级树，非 SVG 知识图谱）
